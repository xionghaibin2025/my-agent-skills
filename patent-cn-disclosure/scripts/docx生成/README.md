# docx生成（skill 底层模板执行器）

`generate.js`：把技术交底书 Markdown 转成统一格式的 .docx。格式规格的全部数值依据见 `../../references/docx-format.md`（经真实案件九轮修订确认，勿随意改动代码内常量）。

## 用法

```bash
node generate.js <输入.md> [-o 输出.docx] [-i 附图目录] [--header "页眉文本"]
```

- 输出默认与输入同名 .docx（同目录）；`-i` 附图目录默认＝md 所在目录。
- 页眉自动取 md 中 `**案件名称**：` 行（→"技术交底书——〈案件名称〉"），`--header` 可覆盖。

## md 约定（生成器识别的语法；格式数值唯一依据＝`docx-format.md` §2，此处不重复登记）

| md 写法 | docx 效果 |
|---|---|
| `# 标题` / `##` / `###` / `####` | 黑体分级标题（带 keepNext 防孤行） |
| 普通段落 | 正文样式（宋体＋Calibri、首行缩进、1.3 倍行距） |
| `**案件名称**：` 等元信息行 | 不缩进左对齐（头部信息） |
| `\|` 表格 | 100% 宽、表头加粗浅灰底、灰蓝边框、跨页不断行 |
| `$$公式$$` | OMML 原生公式居中＋编号（N）右对齐（禁图片公式） |
| `$公式$` | 行内 OMML |
| `![图N　图题](文件.png\|宽=560)` | 居中插图＋加粗图题（`|宽=` 可省） |
| ```` ```mermaid ```` 围栏 | 源码不落 docx（渲染 PNG 后用其后的图片行落图） |
| `> 引用` | 楷体灰色、左缩进 |
| `## 注意事项` 整节 | 红字（过程稿给书写者，定稿删除） |
| `【待确认：…】`（任意位置） | 红字（含表格单元格内） |
| `【提示：…】`（任意位置） | 红字（书写者提醒，v2.1 起第四类） |
| 附图说明/参考文献节条目尾部`（…）` | 红字（过程稿说明性括号） |

## 依赖与维护

- `node_modules/`：docx@9.8.1（自真实案件已验证安装复制而来，**勿重复 npm install**）；Node 运行时本机已有。
- 生成后必做：documents:docx 的 postcheck.py 全项通过＋关键页视觉抽查（见 docx-format.md §3 管线）。
