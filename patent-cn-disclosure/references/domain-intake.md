# 案件接入：案件文件夹与外接参考（任何案件开工必读）

本 skill 通用层不含领域知识。每个案件的领域知识经**案件文件夹**外接；本文件定义其结构、索引规范与降级路径。

## 1. 确定案件文件夹

开工第一句先确认：案件文件夹在哪？

- 用户已指定路径 → 用该路径。
- 未指定 → 建议当前任务文件夹（遵循所在工作区的任务归档规则），列出将创建的子目录，经确认后建立。
- 已存在案件文件夹（续案/改稿）→ 直接复用，先读最近的交付稿与问题清单，不另建。

## 2. 案件文件夹结构

```
<案件文件夹>/
├── 1_案件材料/          # 发明人材料：技术方案文档、核心代码、参数表、实验记录、
│                        #   会议纪要、图表原件等（来源路径在索引中登记）
├── 2_参考专利/          # 已下载的领域相关专利全文（md/docx/pdf/txt）＋
│   └── 参考专利索引.md  #   本索引（规范见 §3）
├── 3_参考交底书/        # 同领域真实交底书（结构基准，0～1份即可）
└── 交付物/              # 交底书、权利要求草稿、问题清单落这里（时间戳命名）
```

- 子目录可按需增建（如 `图源/`），但三个外接目录名固定，便于跨会话复用。
- `1_案件材料/` 每份材料在《参考专利索引.md》的"案件材料登记"区登记来源绝对路径——正文引用数字与事实时须能溯源。
- 参考材料**只读**：不修改、不移动；确需摘录建副本放案件文件夹。

## 3. 《参考专利索引.md》规范

`2_参考专利/参考专利索引.md` 是外接参考的总入口，两张表＋一段状态：

```markdown
# 参考专利索引（案件：____）

## 参考专利表
| 编号 | 公开号/专利号 | 名称 | 申请人 | 用途 | 关键特征摘记 | 本地文件 | 来源URL |
|---|---|---|---|---|---|---|---|
| P1 | CN… | … | … | 区别对照D1 | 一句话：最接近理由＋它怎么做 | P1_xxx.md | https://… |
| P2 | CN… | … | … | 措辞参照 | 权利要求句式/步骤化写法值得模仿处 | P2_xxx.md | https://… |
| P3 | CN… | … | … | 结构模仿 | 章节组织/背景技术写法参照 | P3_xxx.md | https://… |

## 案件材料登记
| 材料 | 内容 | 原始绝对路径 |
|---|---|---|
| 方法说明文档 | … | E:\…\xxx.md |
| 核心代码 | … | E:\…\*.py |

## 状态
- D1（最接近对比文件）：P1（或"未钉住"）
- 查新执行方与时间：____（如"会话A，2026-10-xx"）
- 索引更新时间：____
```

**用途枚举（固定三类）**：
- `区别对照D1`：最接近的现有技术，用于第一章 D1 一段话介绍与区别段写作（不逐特征比对、不列特征一览；最多 1 篇主比对＋若干 D2 补行）。
- `措辞参照`：学其权利要求/步骤化描述的**语言写法**，不抄技术内容。
- `结构模仿`：学其章节组织与背景技术写法，不抄技术内容。

**索引纪律**：
- 每行必须有本地文件与（能查到时的）来源URL；**禁止**无出处条目，禁止编造公开号。
- 用途为空或"背景"的条目只作技术背景列举，不做逐项展开。
- 摘记须基于实际读过该专利全文或摘要；只读过摘要时在摘记中注明"仅摘要"。

## 4. 参考交底书的用法

`3_参考交底书/` 放同领域真实交底书（0～1 份）。用法：**只学结构与颗粒度**——各章写多细、流程怎么拆步、实施例怎么落地；技术内容、术语、数字一律不抄。有参考交底书时，成文前先通读一遍并记录其结构要点；无则直接用 `disclosure-template.md`。

## 5. 降级路径（缺什么都不停笔）

| 缺失 | 处置 |
|---|---|
| 无《参考专利索引.md》但 2_参考专利/ 有文件 | 现场建立索引（读文件→填表），向用户展示后继续 |
| 2_参考专利/ 为空（未做查新） | 跳过 D1 锁定：第一章按材料所述现有做法/本领域常规写缺点；区别特征相对"材料/常规做法"按纯数字编号并标明未经对比文件钉死；文头问题清单记"查新未做，创造性表述为临时口径" |
| 只有检索清单无全文 | 按摘要口径写背景，逐条标"仅摘要，未通读全文"，禁止装作已读全文 |
| 无 1_案件材料/（只有口头 idea） | 先与用户问答补齐三要素（技术问题/手段/效果）与关键步骤，再进入撰写；缺太多时明确列出所需材料清单并暂停 |
| 无参考交底书 | 直接用内置模板 |
| 申请人/发明人未知 | 占位符 `[待填写]`，问题清单记录，不阻塞 |

## 6. 通用层纪律（对使用会话）

- 案件领域词汇（模型名、算法名、机构名等）只出现在案件层文件与交付物中；**不得**写回本 skill 的任何文件。
- 交付正文中的敏感信息按脱敏规则处理（见 disclosure-template.md §脱敏）；内部资料（如用户单位交底书原件）只留在 `3_参考交底书/`，不得摘抄进通用模板。
