# 交付自检清单（Step 8 必做；发现问题直接修订正文再交付）

自检用于**修订正文**，默认不单独输出自检报告；**禁止**把自检清单写成交底书一章。

**版本适用标注（v2.0 起）**：〔通用〕＝安全红线/正确性类，**A/B 两版同守**；〔A〕＝结构/数量类，仅对齐版（A版）适用，B版跳过。混合行按主要属性标注，其中红线子句两版仍守。发明案件全查适用项；含公式时 §2 必核。

## §1 逻辑与闭环

- [ ]〔通用〕技术方案完整闭环（输入→处理→输出），模块上下游衔接？
- [ ]〔通用〕分支样本（边界、异常、低置信等）有明确处理路径？依赖项有交代？
- [ ]〔通用〕关键点章与方案章呼应：每条保护点是**可实施机制**（输入/判定/控制/输出怎么做），不是罗列对象？
- [ ]〔A〕1.1 有总起引言段（先引入话题再点方向，未直接从"方向一"开写）？
- [ ]〔A〕3.1 已按"场景与参与者／标题对象如何进入系统／高频过程引导"铺垫？
- [ ]〔通用〕高频术语已在文首缩略语节（或随文首次出现处）定义且全文同词？
- [ ]〔通用〕**标题贯穿**：案件名称中的领域实词在方案各处作为同一执行主体出现，未被更空的上位词替换？
- [ ]〔通用〕**术语贴合**：用词只看标题和场景像不像本领域？错位词已整篇换成领域表述？
- [ ]〔A〕3.3 与 3.4 对应：3.3 按框图拆独立模块；3.4 逐项对应 S1–Sn（无漏步、无多步混一段）？
- [ ]〔A〕实施例 ≤2 个；〔通用〕实施例与场景/框图同名（名称一致性）、覆盖主路径＋一条已有分支？

## §2 公式与参数一致性（含公式时必核）

- [ ]〔A〕逐式符号说明（毕业论文式）、无集中符号表？〔通用〕每个符号（含下标）都说明到位（充分公开）？
- [ ]〔通用〕分隔符全文统一（`$$…$$`/`$…$`）；同一字母不兼指两对象；同一物理量全文同形同义？
- [ ]〔通用〕式面正确性（运算符/括号配对/上下标/缺项多写/指数分母逐式目检）？量纲常理？不等式方向与文字含义一致？
- [ ]〔通用〕**公式与流程互推**：主式能与方案步骤/模块职责逐步对应，无"文字一套、公式另一套"？
- [ ]〔通用〕边界情形（空输入/单元素/分母为零/达上下界）有处理或不与主式矛盾？
- [ ]〔通用〕参数表与各处取值一致；关键阈值交代来源（经验/实验/可调）？
- [ ]〔通用〕材料式保真（未改写成简化模板）；补写式已在问题清单注明？修订联动（改式后文字/参数/实施例同步）？

## §3 格式、引用与清洁

- [ ]〔通用〕交付文件名＝`{案件名}_{YYYYMMDDHHmmss}.md/.docx`；未覆盖旧稿？
- [ ]〔通用〕mermaid 流程节点**可见标签含步骤号**；正文"如图N"与图序一致；图题与附图说明逐字一致？
- [ ]〔通用〕章节引用指向真实存在的章节？
- [ ]〔通用〕引用的专利均有真实公开号（无编造）；**只列公开号与名称**（无单位/申请日/同族）；只读过摘要的标"仅摘要"？
- [ ]〔通用〕**无本地内部文件名引用**（本地资料只作背景素材）？
- [ ]〔通用〕文末清洁：无 skill 名、无自检清单、无"教学示例/虚构/不构成法律承诺/AI生成"等元信息；无"（全文已通读）"式自证表述？
- [ ]〔通用〕脱敏已过且未把标题领域对象脱成空上位词？
- [ ]〔通用〕交付回复含路径清单、摘要、待确认事项？

## §4 法定要件与创造性主线（硬项，两版同守）

**D1 与特征编号口径**：
- [ ]〔通用〕有 D1 时：1.1 用**一段话**介绍（公开号＋名称＋一句它怎么做），**无逐特征比对表、无特征一览**；**随后另起一段写与 D1 的区别（两段篇幅约 1:1，区别段至多约其 2/3）**？
- [ ]〔通用〕全文用**纯数字编号**（1、2、3…，锚定关键点章）；完整中文句中编号最多句末括注；离开编号仍能读懂？
- [ ]〔通用〕无 D1 时：未点名假 D1、未编公开号；已写明"未钉住对比文件"？

**三段绑定与删除测试（硬项）**：
- [ ]〔通用〕每个特征能填出"特征→技术效果→实际解决的技术问题"？
- [ ]〔通用〕**第二章问题句不含本发明手段词**（含指引/暗示也不行）？
- [ ]〔通用〕协同特征按整体论述；效果章每条优点把构造写进句子、无无主优点？
- [ ]〔通用〕做过删除测试（删掉仍能解决问题的移入优选特征）；必要特征每条带方案对应关系；未写成"根据权利要求1…"权项句式？
- [ ]〔通用〕≥2 组无共同必要特征时已写明总发明构思或建议拆案？

**客体（软件/算法类必核）**：
- [ ]〔通用〕技术三要素齐备（技术手段/技术问题/技术效果）？绑定具体技术环境（执行主体、被控对象、数据来源、作用对象）？

**参数可获得性（充分公开）**：
- [ ]〔通用〕无"只有功能限定却无任何获得方式"的参数？无无出处魔法数？

**表述风险（防自伤）**：
- [ ]〔通用〕慎用"必须、唯一、最佳、最优、所有情况"；**背景技术不自认**；客观陈述不贬低？

## §5 权利要求草稿专项（两版同守）

- [ ]〔通用〕独权只含必要技术特征（A版＝6.1）；每个"步骤N"在交底流程上有同义节点（无多步、无漏步）？
- [ ]〔通用〕从权只引用在先权项；互斥分支未写成并列？
- [ ]〔通用〕每个"所述"有前置；全文无公式、无宣传语、无待确认标记？
- [ ]〔通用〕主题名称各项逐字一致；**编号纯数字**；权项↔交底对照表已附（标注为代理工作表）？

## §6 文风与排版专项（两版同守；机械项给出统计口径）

**文风（细则见 defensive-writing.md §1）**：
- [ ]〔通用〕**括号密度**：逐段统计 ≤1/3；**全篇无括号嵌套**？
- [ ]〔通用〕**无 3 连及以上横线**（跳过 markdown 分隔线行）；成对插入语为提示级？
- [ ]〔通用〕无生僻自创词（对照术语定义：未定义且非领域通用词逐一排查）？
- [ ]〔通用〕无四字断言式文言压缩（方案主链抽读：主谓宾与技术因果齐全）？
- [ ]〔通用〕"公知"已全文替换为"通用手段/常用手段"；标题无括号或≤1个？
- [ ]〔通用〕**用词替换表** grep（`同族|显式|消费|业务`）0 命中（同形异义词人工排除，如"消防"）？
- [ ]〔通用〕**单位规范**：距离默认 km、<1 km 才用 m（抽查全部带单位数值）？
- [ ]〔通用〕关键点条目**尾注只到章/步骤号一级**（无"式(n)"堆叠、正文已注明的不重复标注）？
- [ ]〔A〕3.4 含前置准备步骤时，主链 S1 前有过渡句（如"正式方法流程如下。"）？
- [ ]〔通用〕**过度防御扫描**（D1–D10 信号句 grep）：命中逐条过必要性五问，纯辩护删除？
- [ ]〔通用〕**关键数字保真**：技术要素梳理中的关键数字清单逐个 grep 断言？

**排版（docx，规格见 docx-format.md §2）**：
- [ ]〔通用〕公式全部 OMML 原生，**零公式图片**？
- [ ]〔通用〕每图有**加粗**图题（图N　图题）、居中；图内无图名；框图完整闭合无裁切、**图元不重叠**；单图不占整页？
- [ ]〔A〕数量上限：1.2 缺点≤6、效果≤6、必要特征≤6、实施例≤2、替代方案3–4点？
- [ ]〔通用〕头部信息表字段＝案号/交底书名称/申请人/发明人/撰写人/撰写人电话/E-mail；页眉＝"技术交底书——〈案件名称〉"；页脚页码？
- [ ]〔A〕结构对齐金标准：附图说明/参考文献为三级标题（###）；实施例小节带 7.x 节号？
- [ ]〔通用〕章节标题无模板提示语残留（grep `≤[0-9]+[条个]|（必要技术特征）`）？
- [ ]〔通用〕**红字两阶段**：过程稿红字（注意事项节/【待确认】/【提示】书写者提醒/尾部说明括号）已交用户复核；**定稿版红字清零**（C00000 计数＝0）？
- [ ]〔通用〕生成走 generate.js 管线：postcheck 全项通过＋关键页视觉抽查＋写后回读核验？

## 处理原则

发现问题**直接改稿**再交付（缺必要技术事实时除外——写入问题清单）。公式类：§2 有误须改公式并联动修订各处。法定要件类：三段绑定与删除测试不过＝改稿后交付；门禁"不过"允许成文（降级写），但禁止假 D1、禁止空喊创新性。文风类：§6 命中按 defensive-writing 处理规则修订后重跑统计。
