# 文本、公式与参考文献提取

## 文本底本选择（按优先级）

1. **paper-fetch 的 provider markdown**：入口 A 归档中已有、或入口 B 委托返回 markdown 模式时，优先以其 markdown 作为文本底本——provider 端已做过公式/表格的语义转换，公式损失最小。把它保存为 `工作区/结构/底本.md`，后续 `chunk_split.py --input 底本.md` 直接使用，跳过 PDF 直提。
2. **PDF 直提**：仅本地 PDF 或 provider markdown 不可用时，用 `pdf_structure.py` 的逐页 `get_text("text")` 输出。已知限制：数学排版（分数线、上下标、负号）会丢失或错位，公式必须重建（见下文）。
3. 不使用 `extract_image` 类位图直出充当任何文本来源。

## 逐页文本的清理

合并逐页文本为全文时，宿主完成一次性清理并记录到说明文件：

- 去页眉/页脚/页码的重复行（对照相邻页识别）；
- 保留段落结构，不合并跨行断词；
- 广告、版权样板、出版社信息块整段删除并在说明中注明；
- 章节标题保留原文，翻译时转为 Markdown 标题层级。

## 公式

- 目标格式：行内 `$...$`、独立 `$$...$$`。
- provider markdown 底本：公式多为现成 LaTeX，核对可疑项即可。
- PDF 直提底本：`get_text` 会把公式拆成碎片行。重建规则：方法部分的编号公式逐条重建；能从上下文确定的写 LaTeX 并正常交付；存在假设（算符选择、求和范围、上下标归属）的，在公式后加译注 `（此处重建含假设：…，待确认）`。**禁止把碎片行原样粘进译文当作公式。**
- `merge_verify.py` 统计 `$$` 块数与"待确认"出现次数，进入验收分面 `formula`；待确认数 >0 时整体最多 degraded，不得报 complete。

## 参考文献

- 保留英文原文，不翻译、不重排、不删减。
- `pdf_structure.py` 输出参考文献起止页与条数估计（识别 `References`/`Literature Cited` 节 + 条目模式）；估计值仅供核对，宿主逐条计数后写入说明文件。
- 超长文献（>100 条）用户未要求逐条转录时，可保留节选 + 条数声明，但必须在说明文件和验收分面 `refs` 中如实记录"节选，原文 N 条"。
- 正文中的引用标号（如 ¹、[12]）在译文中保留原样。

## 图注与表格

- 图注（`Fig. N |` 后的文字）不进正文块，由截图与译文中的图片位置承接；翻译时在图片下方以中文简述图注要点（可选，用户未要求时可省）。
- 表格：小表用 Markdown 表重建；跨页大表或复杂合并单元格表格，截图法处理（同 figures.md 渲染规则，`Table N` 定位），并在说明中注明。
