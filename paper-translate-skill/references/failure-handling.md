# 失败处理与降级决策表

先读对应行再行动；同一问题最多重试一次，重试前必须改变输入（参数、底本或方法），禁止原样重跑。

| 症状 | 首选处置 | 降级路径 | BLOCKING 条件 |
|---|---|---|---|
| PDF 打不开 / 页数为 0 / 文本层为空 | 损坏或扫描件：经 paper-fetch 重新获取（DOI 已知时成功率最高） | 重获失败 → `source_unusable` | 重获也失败 |
| 图注定位数 < 正文引用的最大图号 | 调 `--caption-min-width` 降低阈值重跑；仍缺 → 在整页图上量坐标，`--coords` 覆盖缺的图 | 该图以坐标覆盖交付，渲染报告注明 | 坐标也无法确定 |
| 截图对照发现缺面板/截断/混入题注 | 读渲染报告条带坐标，调 `--page-top`/`--x-pad` 或单图 `--coords` 重渲 | 仍缺陷 → 该图标记 `figure_suspect`，译文中暂不链接，验收记 degraded | 多数图失败 |
| 水平范围吃进旁栏正文 | 确认单栏约束规则生效（规则 4）；手工用 `--coords` 收窄 | — | — |
| 跨页图取到错误页 | 核对图注 y0 与 `--page-top-caption` 阈值；调阈值重跑 | `--coords` 手工指定两页拼接（分两段渲染） | — |
| 翻译块缺失 / 块号断档 | merge_verify 报错会点名缺失块号；补译该块重跑 | — | 用户要求放弃该块 |
| 配对率低 / 孤立引用块 | 读 merge_verify 的孤立块清单，定位是漏译还是格式错误；补译或修正格式 | — | — |
| 图片断链 | 检查相对路径与文件名大小写；重命名同步 | — | — |
| 公式重建失败 | 保留原文行 + 译注"公式未重建"，计数进 `formula` 分面 | 公式密集且 provider markdown 可用 → 换底本重提；仍失败 → 考虑 BabelDOC 生成对照 PDF 作参考底稿（不进交付） | — |
| 补充材料获取失败 | 沿用 paper-fetch 的 `asset_failures[*].reason` 原样报告 | `asset` 分面记未获取，整体 degraded | — |
| paper-fetch 不可用 | 本地 PDF 继续全流程 | 补充材料未获取（degraded） | 既无本地 PDF 又无 paper-fetch |
| 覆盖冲突 | 旧文件移入 `工作区/旧版/` 后写新件 | — | 用户未授权覆盖已有可用交付 |
| 磁盘/编码异常（中文路径写失败等） | 改用 ASCII 临时目录写出再移动 | — | 持续失败 |

## 禁止事项

- 不得用 `extract_image` 位图直出替代渲染法交付（旧流程 37 张缺陷的根因）。
- 不得在未做整页对照的情况下把截图标记为已验收。
- 不得为凑配对率把未翻译的英文段落静默删除。
- 不得把"补充材料未获取""公式待确认"从报告中略去。
- 降级交付必须仍可追溯：渲染报告、验收 JSON、说明文件三处的降级描述一致。
