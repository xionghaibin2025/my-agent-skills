# 截图规范与对照验收

## 基本命令

```bash
python scripts/render_figures.py <PDF> --out <论文产物目录>/图片 [--figs 1,2,5] [--ed] \
    [--dpi 300] [--names '{"1": "Fig01_描述"}'] [--coords 坐标覆盖.json] [--preview-dpi 150]
```

默认渲染全部正文图；`--ed` 附带 Extended Data 图；`--names` 指定输出文件名（缺省 `FigNN.png`，交付前由宿主重命名为 `FigNN_描述.png`）。每次运行同时输出 `整页/pageNN.png`（涉及图的所有页的整页渲染）与 `渲染报告.json`（每图的页码、PDF 磅坐标条带、输出尺寸）。

## 渲染法六条版式规则（脚本内置，勿手工绕过）

以下规则经旧流程 37 张返工图验证，是定位正确性的依据：

1. **图注识别**：文本块匹配 `Fig. N` / `Figure N` / `Extended Data Fig. N` 且块宽 >150 磅（排除正文行首引用）。
2. **条带**：本图注顶部之上、上一图注底部（或页顶装饰下缘）之下的竖直区间。
3. **水平范围**：条带内位图 + 矢量绘图（剔除通栏细分隔线、页缘装饰竖线）+ 非正文小文字标签的包络，外扩 25 磅。
4. **单栏图约束**：条带内图注栏旁存在正文段落块时，水平范围约束到图注栏 ±12 磅，外扩收窄为 4 磅。
5. **跨页版式**：图注位于页顶（y0 < 150 磅且非首页）时，图形取上一页的图形包络，下界止于其下方首个正文块。
6. **页顶装饰**：条带上界取页眉细线/刊头色带/文本页眉的下缘（脚本自动检测三种形态）。

所有阈值可经命令行覆盖（`--caption-min-width`、`--page-top`、`--x-pad` 等），覆盖值必须写入渲染报告的 `overrides` 字段。

## 坐标覆盖（fallback）

版式自动定位失败的单张图，用 `--coords` 传 JSON：

```json
{"3": {"page": 7, "rect": [60, 251, 560, 572]}}
```

rect 为 PDF 磅 `[x0, y0, x1, y1]`，来源必须是宿主在整页图上量测的结果，并记录进渲染报告。禁止无出处坐标。

## 对照验收（每张交付图必做）

1. 打开 `整页/pageNN.png` 与对应截图，核对：图号内容一致、多面板齐全（对照图注列出的 a/b/c…面板）、坐标轴与图例完整、无题注/页眉/邻图混入、无截断。
2. 逐图记录结论到渲染报告附表（宿主回填 `checked: true/false`）；`false` 的图标记 `figure_suspect`，按 failure-handling 重渲。
3. 尺寸合理性：300 DPI 下交付图宽通常 ≥1200 像素；异常小（<600 像素宽）提示条带过窄，回查水平范围。
4. 整页对照图是交付证据的一部分，随 `图片/` 一起归档，不得删除。

## 表格截图

`Table N` 定位规则与图注相同（`--tables` 开关），条带取题注上方区间；表格截图命名 `TabNN_描述.png`，验收同上。

## 已知边界

- 图注在图上方或侧方的版式（少数老期刊）不在六条规则覆盖内，直接走坐标覆盖。
- 旋转页/横向大图：脚本按页面原始坐标系渲染，横图输出即为横向 PNG，无需特殊处理；但对照验收必须确认没有把邻栏裁入。
- 位图型 PDF（扫描件）：无文本层，图注定位不可用，整篇按 `source_unusable` 或退化人工处理。
