# 脚本说明（paper-translate-skill / scripts）

四个确定性脚本覆盖状态机的机器步骤；翻译本身由宿主完成（见 `../references/workflow.md` 阶段 7）。首次使用前必读本文档。

## 代码索引与执行顺序

| 顺序 | 文件 | 功能 | 输入 | 输出 |
|---|---|---|---|---|
| 1 | `pdf_structure.py` | 逐页文本、图注/表注定位、位图盘点、DOI 探测、参考文献节估计 | PDF 路径 | `第NN页.txt`、`结构.json`、`图片盘点.txt` |
| 2 | `render_figures.py` | 渲染法截图（六条版式规则 + 坐标覆盖）+ 整页对照图 + 渲染报告 | PDF 路径 | `FigNN.png`、`整页/pageNN.png`、`渲染报告.json` |
| 3 | `chunk_split.py` | 全文按段落边界分块 | 清理后全文 txt / provider markdown | `块NN_原文.md`、`分块清单.json` |
| 4 | `merge_verify.py` | 合并译文块、注入 front matter、结构化校验 | `块NN_译文.md` 集合 | `<论文名>_双语对照.md`、`验收.json` |

典型单篇流程：

```
pdf_structure.py 论文.pdf --out 工作区/结构/
render_figures.py 论文.pdf --out 图片 --names '{"1":"Fig01_描述",...}'
# （宿主：合并逐页文本并清理 → 逐图对照验收 → 翻译各块）
chunk_split.py --input 工作区/全文清理.txt --out 工作区/块/
# （宿主：逐块写 块NN_译文.md）
merge_verify.py --dir 工作区/块 --out 论文名_双语对照.md --title ... --doi ... --source-pdf ...
```

## pdf_structure.py

- 参数：`pdf`、`--out`、`--caption-min-width`（默认 150 磅，图注块最小宽度）。
- DOI 探测：元数据 subject/keywords/title → 前 3 页正文正则。探测不到为 null，不代表无 DOI。
- 参考文献条数为模式估计（`[N]` 或 `N.` 开头行），交付前宿主必须逐条核对；估计值仅供 sanity check。
- 已知限制：`get_text("text")` 丢失数学排版（见 extraction.md 公式规则）；扫描件无文本层时字符数为 0，应转 `source_unusable` 处理。

## render_figures.py

- 版式六规则、坐标覆盖、表格截图的完整规则见 `../references/figures.md`；本文只记实现要点。
- `--coords` 的 JSON：`{"3": {"page": 7, "rect": [x0, y0, x1, y1]}}`，rect 为 PDF 磅，页码 1-based；坐标必须来自宿主在整页图上的量测。
- `--names` 的键为图号字符串（含 ED 图时同样按图号）；表格命名前缀 `Tab`、ED 图 `EDFig`。
- `渲染报告.json` 每图含 `mode`（auto/crosspage_auto/table_auto/coords_override）、`strip_rect`、`checked`/`figure_suspect`（宿主对照验收后回填）。
- 覆盖已存在的 PNG 前不会自动备份；批量重渲同一目录时先自行归档旧版（工作区纪律见 presets.md）。
- 依赖：pymupdf、pillow。Windows 控制台中文输出已做 UTF-8 重配置。

## chunk_split.py

- 段落 = 空行分隔；单段超过 `--size` 时独立成块、不截断；分块清单记录字符覆盖区间，可核对全文无遗漏。
- 输入建议是"清理后全文"（页眉页脚已去）；直接喂逐页拼接文本会把页眉混进段落。

## merge_verify.py

- 退出码 2 = 块配对错误（缺译文块/多余块），先补齐再重跑。
- `pairing_rate` = (EN 引用块 − 孤立块) / EN 引用块；孤立块 = 后面没有紧跟中文段落的引用块。低于 0.98 判"需修复"。
- 图片链接按输出 md 所在目录解析相对路径；`broken_links` 非空判"需修复"。
- `refs_count_estimated` 用宽松模式（`[N]`、`N.`、"Author (YYYY)"）估计，以宿主逐条计数为准。
- `overall_pre` 仅脚本预判；`asset`/`output` 分面与终判由宿主按 `../references/acceptance.md` 回填。
- 纯中文模式（`--mode zh`）只影响 front matter 标记；配对率校验仍按双语格式跑，纯中文交付由宿主改用段落覆盖率口径（见 presets.md）。

## 依赖与版本

- Python 3.10+（开发验证 3.12.8）；pymupdf ≥1.24（旧流程在 1.28.2 验证）；pillow ≥9。
- 无网络、无 LLM 依赖；所有脚本可离线重跑。
