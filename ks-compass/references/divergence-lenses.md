# 发散视角

发散阶段只产出候选，不评价。每个候选写一句问题，加一句它挑战的默认假设或解决的矛盾，注明来自哪种视角。按材料选三四种视角，不必全部使用。

## 一、从数据出发

- **异常与残差**：模型或主规律解释不了的样本、点位、时段在说明什么？把残差的空间或时间格局当作研究对象。
- **规律反转**：哪个子集里主规律不成立，甚至方向相反？反转的条件本身可能就是边界条件类问题。
- **尺度切换**：换一个空间尺度（点位、剖面、流域、区域）或时间尺度（事件、季节、年际）看，结论是否改变？改变的位置在哪里？
- **变量换角色**：被当作控制变量、背景或噪声的因素，是否可能正是主角？
- **反向提问**：把"X 如何影响 Y"反过来问："Y 的格局能否反推 X？"正演问题常可改写为反演问题。
- **负结果与失败的分析**：预期中的关系没有出现，说明哪个假设不成立？

## 二、从文献出发

- **找矛盾**：两组研究结果相互冲突时，是否存在一个条件变量能同时解释两者？被当作必然的权衡，是本质如此还是现有方法造成的？
- **条件变化后重看旧问题**：过去因数据、方法或观测手段不足而放弃或未解决的问题，哪些条件现在变了？
- **假设反转**：列出领域默认成立的前提，逐条问"如果相反会怎样"，看哪条反转后能导出可检验的预测。
- **失效边界**：公认的方法或规律在什么条件下失效？系统地找出失效条件，本身就是贡献。

## 三、跨领域

- **结构类比**：去掉专业名词，用关系描述问题（例如"一个系统接收输入，经过不同路径和不同停留时间后输出，输出的组成随路径变化"），再找结构相同的其他领域。可借鉴的例子：
  - 流域或含水层的响应 ↔ 信号处理与系统辨识中的传递函数；
  - 地下水年龄与溶质运移 ↔ 化学工程中的停留时间分布；
  - 盐分或污染物的空间累积 ↔ 生态学中的源汇格局；
  - 水化学演化路径 ↔ 状态转移与路径分析；
  - 土壤或地貌过渡带 ↔ 生态学中的交错带理论；
  - 元素迁移与富集 ↔ 生态化学计量与物质循环。
  类比须在机制层面成立，并能导出本领域可检验的预测；只有表面相似的类比不采用。
- **交叉矩阵**：列出本问题的 5–8 个核心概念和另一领域的 5–8 个核心概念，逐格问"把那个领域的概念用到这里意味着什么"，挑出能导出可检验问题的格子。

## 四、问题重述

改变问题的某个要素，看问题是否变得更容易、更重要或更有新意：

| 改变 | 例子 |
|---|---|
| 目标 | "提高预测精度" → "找出预测失败的条件" |
| 粒度 | 流域平均 → 子流域或单井差异 |
| 主体 | "哪些因素控制盐分" → "盐分格局能说明哪些过程" |
| 方向 | 正演模拟 → 由观测反推过程或参数 |
| 时间尺度 | 多年平均 → 事件尺度的响应 |

## 五、约束的增加与去除

- **去除约束**：如果任何量都能测、任何时段都有数据，最想回答什么问题？再退回来，看现有数据能回答它的哪一部分。
- **增加约束**：如果只能用一个变量、一种方法或一个时段，最有说服力的问题是什么？约束常能逼出更锋利的问题。

## 六、候选过于集中时

多样性检查发现候选集中在同一视角、同一粒度或同一句式（如"在某地用某方法分析某变量"）时，再发散一轮：

- 这批数据支撑的最大胆的问题是什么？
- 目标领域顶级期刊的编辑读到它，会期待回答什么问题？
- 如果主结论反过来成立，领域里哪些认识需要修改？
- 被放弃或被认为不可行的方法，现在为什么可能可行？
- 把目前的局限（数据短、样本少、区域特殊）当作问题本身，能问出什么？

## 多模型发散

需要更多视角时，经 ai-cross 让两三个不同厂商的模型各自独立发散：

- 每个模型拿到相同的数据概况摘要、线索表和目标，不看彼此的答案；
- 合并时去重，保留每个候选的来源模型；
- 这一步的目的是增加多样性，不作为候选成立的证据；
- 数据概况和未发表的想法都属于外发内容，发出前须经用户授权，只发必要的最小摘要，必要时去除站点坐标等敏感信息。
