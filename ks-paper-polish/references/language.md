# 通用语言规范

## 时态速查表

| 章节 | 主要时态 | 适用情境 | 示例 |
|------|----------|----------|------|
| Abstract | 过去时为主 | 描述已完成研究 | "This study investigated..." |
| Introduction | 现在时+现在完成时 | 一般事实+连接研究 | "Climate change affects..." |
| Methods | 过去时 | 描述实验步骤 | "Samples were collected..." |
| Results | 过去时+现在时 | 结果+图表引用 | "Figure 1 shows..." |
| Discussion | 现在时为主 | 解释意义 | "This suggests that..." |
| Conclusion | 现在时 | 陈述结论 | "This study demonstrates..." |

### 三种核心时态场景

| 时态 | 场景 | 示例 |
|------|------|------|
| 一般现在时 | 普遍事实、图表描述 | "Water flows downhill" |
| 一般过去时 | 具体实验、特定结果 | "We collected 50 samples" |
| 现在完成时 | 连接过去与现在的研究趋势 | "Recent studies have shown..." |

## 语态规范

### 现代趋势
> Nature明确推荐主动语态："读者发现主动语态能更清晰传达概念和结果"

### 选择原则

| 语态 | 适用场景 | 示例 |
|------|----------|------|
| 主动 | 强调作者贡献、清晰简洁 | "We analyzed the samples..." |
| 被动 | 行为主体不重要、强调程序 | "Samples were analyzed..." |

### 核心原则
以清晰为准，不为追求形式统一而机械改写。方法步骤可自然使用被动语态，作者判断和主要发现通常用主动语态更直接。

### 比较
| 被动（传统） | 主动（推荐） |
|--------------|--------------|
| "It was found that..." | "We found that..." |
| "The samples were collected..." | "We collected the samples..." |

## 主张强度与Hedging

Hedging用于匹配证据强度，不是默认的“学术化”操作。直接结果应直接陈述；机制解释再根据证据使用 `indicate`、`support`、`suggest` 或 `may reflect`。完整判断见 `claim-calibration.md`。

### 强度等级

| 强度 | 词汇 |
|------|------|
| 弱 | might, could, possibly, perhaps |
| 中 | may, can, probably, likely |
| 较强 | would, should, generally |

### 认识论动词
```
suggest, indicate, imply, appear, seem, propose, argue
```

### 禁止使用（过度声称）

| 禁用词 | 替换为 |
|--------|--------|
| prove | suggest, indicate, demonstrate |
| novel | 具体说明新增了什么；有证据时可保留 |
| first | 仅在检索充分且确有必要时使用 |
| undoubtedly | likely, probably |
| definitely | - (删除) |
| certainly | - (删除) |
| groundbreaking | - (删除) |

### 平衡原则
- `prove` 通常过强，但 `show` 和 `demonstrate` 可用于证据充分的结果。
- 不得把作者有支持的明确判断自动改成 `may/could/appears`。
- 禁止双重hedging，如 `might possibly suggest`。
- 同一限制不要在多个章节反复出现，详见 `defensive-writing.md`。

## ESL作者高频错误纠正

### 冠词问题

| 错误 | 正确 | 规则 |
|------|------|------|
| "Results show increase" | "The results show an increase" | 特指用the，泛指用a/an |
| "In conclusion" | 总结过渡语冗余时删除；指具体章节时才用 "in the conclusion" | 两者含义不同，不机械补冠词 |
| "water is important resource" | "Water is an important resource" | 可数名词需冠词 |

### 主谓一致

| 错误 | 正确 | 规则 |
|------|------|------|
| "The data shows" | "The data show" | data是复数 |
| "The information are" | "The information is" | information不可数 |
| "Each samples were" | "Each sample was" | each+单数 |

### 时态错误

| 错误 | 正确 | 规则 |
|------|------|------|
| "The analysis is showing a seasonal pattern" | "The analysis shows a seasonal pattern" | 依实际时态修正，不改变主张强度 |
| "We collect samples yesterday" | "We collected samples yesterday" | 过去动作用过去时 |

### 非正式表达

| 非正式 | 正式 |
|--------|------|
| a lot of | numerous, substantial, considerable |
| get | obtain, receive, reach（按语境） |
| big | 用具体量级或准确比较；不因表达“大”而引入统计显著性 |
| find out | determine, ascertain |
| look at | examine, investigate, analyze |
| thing | factor, aspect, element |

### 指代不明

| 错误 | 正确 | 规则 |
|------|------|------|
| "This shows..." | "This finding demonstrates..." | 明确指代对象 |
| "It is important" | "This result is important" | 避免模糊it |

### 搭配错误

| 错误 | 正确 |
|------|------|
| make a simulation | run/perform a simulation |
| do analysis | conduct/perform analysis |
| make experiment | conduct experiment |
| research about | research on |
| different with | different from |
| according to me | in my view / we suggest |

### 冗余表达

| 冗余 | 简洁 |
|------|------|
| "The color of the soil is red" | "The soil is red" |
| "at the present time" | "currently" / "now" |
| "in order to" | "to" |
| "due to the fact that" | "because" |
| "a total of 50 samples" | "50 samples" |
| "during the course of" | "during" |

### 主题-评论结构（中式英语）

| 错误（中式） | 正确 |
|--------------|------|
| "For the calibration period, it has a high NSE" | "The model achieved a high NSE during the calibration period" |
| "About this problem, we think..." | "We consider this problem..." |

## 连接词分类

### 添加
`also`, `additionally`，或直接用句子之间的事实关系衔接。

### 对比
```
however, nevertheless, in contrast, conversely, on the other hand, yet
```

### 因果
`thus`, `hence`, `as a result`；只有因果关系明确时使用。

### 举例
```
for example, for instance, specifically, to illustrate, such as
```

### 强调
优先直接写出被强调的结果；`particularly`、`specifically` 可在确有对比时使用。

### 总结
```
overall, in summary, to conclude, in general
```

### 使用原则
- 避免过度使用：每段 however/thus 类逻辑连接词至多 2 处；但也不得为避开连接词把它们全删——连续短句之间仍需保留真实逻辑衔接
- 不为避免重复而轮换同义连接词
- 确保逻辑匹配
- 注意标点（however后需逗号）

## 数字和单位规范

### 数字
- **句首**：拼写出来（"Twenty samples were..."）
- **句中**：阿拉伯数字（"We collected 20 samples"）
- **小于10**：可拼写或数字（根据期刊风格）

### 单位
- 使用SI单位
- 数值与单位间空格："5 m"（不是"5m"）
- 范围：5–10 m（不是5-10m）

### p值
- 格式服从目标期刊；APA与许多地学期刊对前导零的习惯不同。
- 精确值优先；极小值通常写作 `p < 0.001` 或期刊指定形式。
- 全文统一变量字形、大小写和小数位，不把某一种统计风格冒充通用规则。
