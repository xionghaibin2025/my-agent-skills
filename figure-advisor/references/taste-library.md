# 参考图库与偏好记录

图库目录由用户配置，确定方式见 SKILL.md 的 D 节。目录结构：收藏的图片直接放在图库目录下，文件名不限；`卡片/` 存说明卡；`偏好记录.md` 存选择记录。目录或文件不存在时，在用户首次要求整理或首次记录选择时创建。分类写在卡片的"图类型"一栏，不从文件名推断。

## 说明卡

每张图一张卡片，放在 `卡片/` 子目录，文件名与图片同名（扩展名为 `.md`）。只在用户要求整理某些图时写卡片，不批量自动生成。

```markdown
# 03统计图表_01

- 来源：期刊、年份、论文题目或 DOI；不知道时写"未知"
- 素材类型：论文原图 / 配色卡 / 公众号海报 / 截图
- 图类型：分组比较 / 关系 / 时间序列 / 空间 / 组图 / ……
- 数据形状：样本量级、是否偏态、组数等可以从图上看出的特征
- 读者先看到什么：
- 子图角色与排版：（组图时填写）各子图回答什么问题，读者按什么顺序看
- 编码：位置、颜色、大小、形状、线型分别对应什么变量；跨子图是否一致
- 尺度与参照：对数轴、共享坐标范围、基线与阈值线、投影、色标上下限、缺测表示
- 证据层次：原始数据、汇总或模型、不确定性、统计标注各用什么方式画出
- 颜色与含义：颜色对应的变量或类别；HEX 仅在能准确取色时填写
```

## 偏好记录

文件：`偏好记录.md`。用户在比较中明确选中或排除某个方案时直接追加一行，不另行确认；用户未表态的不记录。"图类型与数据形状"一栏写明当时的数据情况（如"每组 n=5，右偏"），以免一次排除被推广到不同的数据上。

```markdown
| 日期 | 图类型与数据形状 | 选中 | 排除 | 理由（用户原话） |
|---|---|---|---|---|
| 2026-09-25 | 分组比较，右偏，每组 n≈30 | 对数轴箱线 + 点 | 小提琴 | "小提琴太胖" |
```

## 使用

- 生成候选前，读取偏好记录中图类型与数据形状相近的行：选中过的做法优先列为候选；排除过的做法不作为推荐项，除非当前数据有明确理由，并在推荐中说明。
- 需要参考图时，按卡片的"图类型"和"数据形状"查找，打开对应图片确认后再引用；没有卡片的图可以直接查看，但引用时说明未建卡。
- 参考图用于借鉴排版、主次和配色角色，具体颜色和尺寸仍按当前数据与目标期刊确定。
- 修改或删除已有卡片和偏好记录须经用户确认；新卡片只在用户要求整理时写，新偏好记录按上文直接追加。
