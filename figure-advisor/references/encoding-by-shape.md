# 由数据形状选候选画法

`profile_shape.py` 输出的形状标记与本文件的标记名一致。先按主张确定图的大类，再在大类表中按标记挑候选。同一数据命中多个标记时，候选应覆盖不同标记指向的画法。

## 选候选的规则

- 候选数 2–4 个。至少一个侧重汇总（中位数、均值、区间），至少一个让分布或个体可见，除非样本量太小或太大使其中一种没有意义。
- 用户指定的画法列为候选之一，即使形状标记不支持；在"当前数据上的观感"一栏如实写出问题。
- 坐标变换（对数、asinh）必须在轴标题或刻度上标明，候选表中注明"变换坐标"。
- 涉及汇总和误差线的候选，误差定义（SD、SE、95% CI、IQR）取自用户或已有分析；没有定义时询问，不自行选择。

## 形状标记

| 标记 | 判定（脚本内的阈值为筛查用，可按学科调整） |
|---|---|
| `very_small_n` | 最小组 n < 5 |
| `small_n` | 最小组 n < 10 |
| `large_n` | 某组 n > 200，散点会重叠 |
| `unequal_n` | 组间 n 相差 3 倍以上 |
| `right_skew` / `left_skew` | 偏度 > 1 或 < −1 |
| `span_orders` | 正值最大/最小 ≥ 100，跨两个数量级以上 |
| `many_zeros` | 零值占比 ≥ 20% |
| `has_negative` | 含负值，对数变换不可用 |
| `bimodal` | 双峰系数 > 0.555 且 n ≥ 20 |
| `outliers` | Tukey 1.5 IQR 外的值占比 > 5% |
| `discrete` | 取值种类少（≤ 7，或整数且 ≤ 15） |
| `unequal_spread` | 组间 IQR 最大/最小 ≥ 3 |
| `scale_gap` | 组间中位数最大/最小 ≥ 10 |
| `high_overlap` | 多数组对的 IQR 相互重叠 |
| `many_groups` | 组数 > 8 |

## 分类 × 连续（组间比较）

| 标记 | 常见问题 | 候选 |
|---|---|---|
| `very_small_n` | 箱体由几个点撑出，四分位数不稳定 | 全部点 + 中位数或均值短横线；点 + 用户给定区间 |
| `small_n` | 箱线图和柱图掩盖个体 | 点（抖动或蜂群）+ 箱线；点 + 均值 ± 区间 |
| `large_n` | 散点糊成色块 | 小提琴或半小提琴 + 窄箱线（云雨图）；分位点图；ECDF |
| `right_skew` 且无负值 | 箱体压在底部，长尾占满纵轴 | 对数纵轴 + 箱线/点；原尺度小提琴 + 中位数；原尺度加截断并标注截断值 |
| `many_zeros` | 零值堆在底部，分布被拉歪 | 两段式：零值占比条 + 非零部分分布；asinh 或伪对数轴（标明） |
| `bimodal` | 箱线图把双峰画成一个箱 | 小提琴或密度 + 点；分组直方图小多图 |
| `scale_gap` 或 `span_orders` | 小值组被压成一条线 | 分面各用独立纵轴；对数轴；相对对照组的比值或差值 |
| `unequal_spread` | 柱 + SE 让离散程度看不出来 | 点 + 箱线；点 + 区间（区间定义由用户给出） |
| `discrete` | 小提琴把离散值画成平滑密度 | 计数点图；堆叠比例条；带计数的气泡 |
| `many_groups` | 横轴拥挤、标签倾斜 | 横向点 + 区间，按中位数排序；突出关注组，其余灰色 |
| `outliers` | 离群点决定纵轴范围 | 保留全部点并使用对数轴；或标注离群点后放大主体区域的插图 |
| `high_overlap` | 差异本身很小 | 如实展示分布；需要强调差异时另加差值与区间的子图（差值来自已有分析） |

柱状图只在主张是"总量或比例"、且数据以零为自然起点时作为候选；柱体从零开始，对数轴上不用柱。

## 两个连续变量（关系）

| 情况 | 候选 |
|---|---|
| n < 500 | 散点；需要时加用户已拟合的趋势线与区间 |
| n ≥ 500 或点重叠 | 半透明散点；六边形分箱；二维密度等值线 |
| 任一变量 `right_skew` 或 `span_orders` | 对应轴取对数（标明） |
| 观测值 vs 预测值 | 等比例坐标 + 1:1 参考线；残差子图 |
| 有分组 | 同一面板分色；或按组分面并共享坐标轴 |

## 时间或有序变量

| 情况 | 候选 |
|---|---|
| 时间点少、个体可追踪 | 每个个体一条细线 + 粗均值线 |
| 时间点密 | 折线 + 区间带（区间来自已有分析） |
| 序列多 | 小多图并共享纵轴；关注序列着色、其余灰色 |
| 有缺测 | 保留断开，不插值连线 |

## 矩阵与热图

- 有意义的零点（相关系数、变化量）用发散色带并以零为中心；无符号量用顺序色带。
- 行列按聚类或数值排序，排序方式写进图注。
- 格子少于约 200 个时可在格内标数值。

## 空间数据

- 连续栅格用顺序色带，有明确中点的变化量用发散色带；分类用少量区分度高的颜色。
- 多幅地图并排比较时，投影、范围、色标上下限和缺测颜色保持一致。
- 研究区位图不在本技能范围内，可用 study-area-map（github.com/keros68/xiaoyu-skill）。

## 常用函数

| 画法 | R | Python |
|---|---|---|
| 抖动点 / 蜂群 | `geom_jitter()`；`ggbeeswarm::geom_quasirandom()` | `ax.scatter` + 抖动 |
| 箱线 | `geom_boxplot(outlier.shape = NA)` 配合点层 | `ax.boxplot(showfliers=False)` |
| 小提琴 / 半小提琴 | `geom_violin()`；`ggdist::stat_halfeye()`（需安装 ggdist） | `ax.violinplot()`，用 `get_paths()` 裁成半边 |
| 点 + 区间 | `geom_pointrange()` | `ax.errorbar(fmt="o")` |
| ECDF | `stat_ecdf()` | `ax.ecdf()`（matplotlib ≥ 3.8） |
| 对数 / asinh 轴 | `scale_y_log10()`；`scale_y_continuous(transform = "asinh")` | `ax.set_yscale("log")`；`ax.set_yscale("asinh")` |
| 六边形分箱 | `geom_hex()` | `ax.hexbin()` |
