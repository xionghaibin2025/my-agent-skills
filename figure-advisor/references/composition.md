# 组图方案

## 1. 主张与子图角色

先写一句整张图要让读者相信的话，再给每个子图一个角色。只用数据能支撑的角色，不为凑齐而加子图。

| 角色 | 作用 | 常见内容 |
|---|---|---|
| 背景 | 让读者知道研究对象和设计 | 研究区、采样设计、实验流程 |
| 主证据 | 单独就能支撑主张的那张 | 空间格局、核心对比、主要趋势 |
| 定量汇总 | 把主证据量化 | 分组比较、区域统计 |
| 解释 | 说明为什么 | 驱动因素、贡献分解、SHAP、机制 |
| 验证 | 说明结论可靠 | 观测与预测、不确定性、独立数据检验 |

对每个子图问一句：去掉它，主张是否变弱？答案是否定时，建议移到补充材料。

## 2. 排版候选

给 2–3 种排版并渲染对比。子图已有数据的用真实子图；没有的用灰色占位框，框内写"占位：子图角色"。

| 排版 | 适用情况 |
|---|---|
| 主图 + 侧栏：主证据占左侧大块，其余纵向排在右侧 | 有一个明确的主证据，其余是解释或验证 |
| 上主下辅：主证据占整行，下一行并排辅助子图 | 主证据是宽幅内容（地图、剖面、时间序列） |
| 等权网格 | 各子图是平行比较（不同时期、情景、区域），没有主次 |
| 条带小多图 | 同一变量在多个条件下重复，共享坐标轴 |
| 阅读顺序排列 | 子图构成"背景 → 观察 → 定量 → 解释 → 验证"的推进 |
| 数据 + 示意图 | 定量结果需要机制示意图配合；示意图用独立的中性配色和线型，面积和视觉强度不超过主证据，其中的名称与数据子图一致 |

面积比例不预设固定数值。按最终尺寸渲染后判断：主证据的关键格局一眼能看清，辅助子图的文字和刻度仍可读；达不到时调整面积或减少子图。地图等固定长宽比的子图按其比例安排，不强行拉伸。

## 3. 跨子图一致

- 同一变量或类别在所有子图中使用同一颜色、同一顺序、同一名称和同一符号。
- 需要直接比较的子图共享坐标范围和色标上下限；各自单位不同时保留各自坐标轴。
- 图例只在含义确实共享时合并为一个，放在第一个使用它的子图旁边或统一留白处。
- 对齐的是绘图区的边，不只是子图外框；同行子图上下边对齐，同列子图左右边对齐。
- 数据标记（点、线、区间）在视觉上重于坐标轴、框线和网格；参考线和零线清晰但安静。
- 全图字号不超过三级：轴标题和图例标题、刻度和图例文字、子图标签（加粗）。
- 子图标签的大小写和位置遵循目标期刊。

## 4. 全文配色表

一篇论文建一张表，所有图共用；表放在项目的图件目录，例如 `图件/配色表.md`。已有配色表时先读取并沿用。

| 变量或类别 | 含义 | 颜色（HEX） | 使用的图 |
|---|---|---|---|
| 对照 | 参照组 | #8C8C8C | 图 2、图 4 |

选色顺序：先定角色，再定具体颜色。候选色带从 `assets/palettes.json` 中按角色选取 3–4 套，套在实际图上渲染比较，并用 `scripts/cvd_preview.py` 查看色觉模拟与灰度效果，由用户选定后写入配色表。

- 对照或参考用中性灰；关注的组或方法用最饱和的颜色；其他比较组降低饱和度。
- 连续量用顺序色带；只有存在有意义的中点（零、1.0、基准期）时用发散色带，并以该中点为中心。
- 分类颜色一般不超过 6 种；更多时改用分面、直接标注或把次要类别合并为灰色。
- 不用红与绿表示对立的两类；定稿前用 `scripts/cvd_preview.py` 做一次色觉模拟检查。色觉评估为 `not_assessed` 或 `conditional` 的色带，须在模拟视图中确认各类可区分。
- 用户参考图中的配色可以作为起点，但先按上面的角色重新分配，不整套照搬。

## 5. 组图常见问题

| 现象 | 改法 |
|---|---|
| 每个子图各用一套配色 | 按配色表统一 |
| 主次不同的子图被排成等大网格 | 改为主图 + 侧栏或上主下辅 |
| 同一图例重复出现 | 合并为一个共享图例 |
| 子图被压扁以求对齐 | 调整排版或总高度，保持数据区可读 |
| 大片空白与拥挤并存 | 调整子图跨度，或把图例移入留白 |
| 字体、字号、线宽在子图间不一致 | 用同一主题函数或 rcParams 统一设置 |
| 图内有大标题、图注、引文或水印 | 移到正文图注；投稿图件内只保留轴标签、子图标签和必要的图内说明 |
| 以"Nature 风格"之类代替具体要求 | 写明目标期刊的尺寸与字体要求和本图的设计理由 |
