# figure-advisor：配图方案与审美顾问

## 用途

为已有数据或已有图件找出更好的表达：先看数据的分布形状，再把几种候选画法真实渲染出来并排比较，由用户选定。审美判断依靠渲染结果和用户的参考图库，不依靠固定的个人风格。

## 基本原则

- **分析结果原样使用。** 只读取数据的分布形状来决定画法，不选统计检验、不重新拟合、不改动数值；用户提供的检验结果、误差定义和显著性标注照原样画出，缺少定义时询问。
- **候选靠渲染比较。** 每个候选按最终尺寸实际渲染，拼成对比图后看图判断；未经渲染的方案只作为文字备选，并注明未渲染。
- **候选之间差在表达方式。** 各候选让读者先看到的东西应当不同（汇总值、分布、个体、趋势等），不以只换颜色或线宽凑数。用户指定过的画法列为候选之一。
- **推荐附理由，用户拍板。** 每个候选写一句"读者先看到什么"和一句"它隐藏了什么"，给出推荐及理由，最终由用户选择。
- **风格来自参考与偏好。** 字体、线宽、配色等风格参数取自目标期刊、项目现有图件、参考图库和偏好记录；都没有时采用中性设置并说明。偏好记录中被排除过的做法不作为默认方案再次提出。
- **演示数据须标明。** 组图排版比较可以用灰色占位框代替尚无数据的子图，占位框内写明"占位"；不生成假数据冒充结果。

## 流程

按任务选择入口，只读取该入口需要的参考文件。

### A. 单图选型

1. **问主张。** 这张图要让读者相信什么（组间差异、趋势、关系、空间格局等）；用户未说明时从上下文推断并写明假设。候选按双栏 180 mm 或单栏 88 mm 暂定尺寸渲染；期刊通常到定稿才确定，届时再按其官方作者指南调整。
2. **看数据。** 运行 `scripts/profile_shape.py`（见下文"脚本"），得到每组样本量、偏度、零值比例、离群比例、双峰迹象、组间量级差和重叠程度等形状标记。
3. **列候选。** 按 `references/encoding-by-shape.md` 由形状标记和主张选出 2–4 个候选；已配置参考图库时先读偏好记录（见 D）。
4. **渲染比较。** 写一个脚本，同一份数据、同一最终尺寸、同一 dpi 输出 `cand_A.png`、`cand_B.png` 等，再用 `scripts/contact_sheet.py` 拼成对比图，打开对比图逐个查看。
5. **推荐。** 用表格列出各候选：读者先看到什么、隐藏了什么、在当前数据上的实际观感（压扁、重叠、长尾挤在一端等）。给出推荐和理由，等待用户选择。
6. **配色候选。** 用户选定图型后，如颜色承载含义（分组、数值大小、正负变化），从 `assets/palettes.json` 按颜色角色选 3–4 套色带，套在选定的图上渲染比较，并用 `scripts/cvd_preview.py` 生成色觉模拟与灰度视图。已有全文配色表时沿用，不另选。
7. **定稿。** 目标期刊已定时，查其官方作者指南核对栏宽、最小字号和线宽；按选定方案出正式脚本和图件，渲染后再看一遍；已配置参考图库且用户明确选中或排除某方案时，按 D 记入偏好记录。

### B. 组图方案

按 `references/composition.md`：先写整张图的一句主张和每个子图的角色，再给 2–3 种排版并渲染对比；同时建立或沿用全文配色表（配色候选同样渲染比较），保证同一变量在所有子图和所有图中颜色、顺序、名称一致。子图各自的画法按 A 选定。

### C. 审图与改图

按 `references/critique.md`：同时读图件和生成它的代码，按"主次 → 编码 → 配色 → 对齐与留白 → 文字与字号 → 导出"的顺序列出问题，每条写明影响和改法；把原图与改后渲染拼成对比图一起交付。已经合适的部分不改。

### D. 参考图库与偏好（可选）

参考图库是用户自己的一个文件夹，存放收藏的图、说明卡和偏好记录。位置按以下顺序确定：环境变量 `FIGURE_LIBRARY`；项目 AGENTS.md 或 CLAUDE.md 中写明的路径；用户在对话中指定的路径。都没有时跳过本节和各流程中涉及图库的步骤，其余功能照常使用；首次跳过时告诉用户可以配置图库，之后不再提示。

有图库时按 `references/taste-library.md` 维护：为收藏的图写说明卡，记录用户每次选中和排除的方案。卡片中"用户认可的做法"只写用户认可的内容；模型自己的观察单列并标明。

## 脚本

脚本都带 PEP 723 依赖声明，用 `uv run <脚本>` 运行时自动安装依赖；已有装好 pandas、numpy、Pillow 的环境也可直接用 `python` 运行。

| 脚本 | 用途 |
|---|---|
| `scripts/profile_shape.py data.csv --y 列名 --group 分组列` | 输出形状标记（Markdown 摘要，`--json` 输出 JSON）；支持 csv、xlsx、parquet |
| `scripts/contact_sheet.py cand_A.png cand_B.png --labels "A 箱线+点" "B 对数轴" -o compare.png` | 按原始像素拼接候选图并加标签；各候选须以同一 dpi 渲染，拼接后才能比较实际尺寸 |
| `scripts/cvd_preview.py compare.png` | 输出原图、绿色盲模拟、红色盲模拟和灰度四宫格，用于筛查 |

`assets/palettes.json` 收录 32 套精选色带（分类 10、顺序 14、发散 8），每套注明类型、适用类别数、色觉评估状态、来源与许可；连续色带为 11 个锚点，R 用 `colorRampPalette()`、Python 用 `LinearSegmentedColormap.from_list()` 插值。需要更多选择时，可查 EasyPlot 的完整色带目录（`Rimagination/easyplot` 的 `assets/palettes.json`，1537 套），按色带 ID 引用。

绘图脚本沿用项目已有的语言和绘图栈；没有既定栈时，R 用 ggplot2 + patchwork，Python 用 matplotlib。定稿时如已安装 rfigure（R）或 ultraplot-figures（Python），可按其代码与导出规范出正式脚本。

## 输出方式

- 先交对比图，再给候选表和推荐；表格列：候选、读者先看到什么、隐藏了什么、当前数据上的观感。
- 候选图、对比图和脚本放在项目的图件工作目录；不在项目中时放在当前工作目录的 `figure_candidates/`。
- 结尾写明需要用户做的选择。
